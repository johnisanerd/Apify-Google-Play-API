# Google Play API examples (retired)

> **I've retired Google Play API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For app store data on iOS and macOS, use my **[Apple App Store Search](https://apify.com/johnvc/apple-app-store-search?fpr=9n7kx3)** instead, and start from its example repo, [Apify-Apple-App-Store-API](https://github.com/johnisanerd/Apify-Apple-App-Store-API).

## Use instead

- **[Apple App Store Search](https://apify.com/johnvc/apple-app-store-search?fpr=9n7kx3)**: App Store search results for any keyword across 155+ country stores, with ratings, developer, price and bundle ID. Example repo: [Apify-Apple-App-Store-API](https://github.com/johnisanerd/Apify-Apple-App-Store-API).
- **[Apple App Store Product API](https://apify.com/johnvc/apple-app-store-product-api?fpr=9n7kx3)**: full app details by App Store ID: version history, price, ratings, screenshots, in-app purchases and privacy cards. Example repo: [Apify-Apple-App-Store-API](https://github.com/johnisanerd/Apify-Apple-App-Store-API).
- **[Apple App Store Reviews API](https://apify.com/johnvc/apple-app-store-reviews-api?fpr=9n7kx3)**: app reviews with ratings, text, dates and versions. Example repo: [Apify-Apple-App-Store-Reviews-API](https://github.com/johnisanerd/Apify-Apple-App-Store-Reviews-API).
